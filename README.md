# FS25_RepairPickup

![Status](https://img.shields.io/badge/status-released-4CAF50)
![Platform](https://img.shields.io/badge/Farming%20Simulator-25-4CAF50)
![License](https://img.shields.io/badge/license-custom-lightgrey)

**Feld Reparatur Pickup** ist ein 2017er Pickup mit Feld-Reparatur-Aufbau für Farming Simulator 25 –
mit einem 4.000l-Dieseltank zum Auftanken auf dem Feld, geldbasierter Reparatur und einem kleinen
Hochdruckreiniger zum Scheibenputzen im Kofferraum. Farbwahl für Chassis, Felgen und Aufbau ist
möglich.
